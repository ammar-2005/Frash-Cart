
# FrashCart 🛒

A fast, modern, and responsive e-commerce web application built with the Next.js App Router, React, TypeScript, and Tailwind CSS.

![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-06B6D4?style=for-the-badge&logo=tailwindcss&logoColor=white)

## Features

* **High Performance:** Server-Side Rendering (SSR) and Static Site Generation (SSG) powered by Next.js.
* **Type Safety:** Built end-to-end with TypeScript for robust, maintainable code.
* **Modern UI:** Clean, fully responsive UI designed with Tailwind CSS.
* **Seamless Experience:** Smooth navigation and fast product rendering.
